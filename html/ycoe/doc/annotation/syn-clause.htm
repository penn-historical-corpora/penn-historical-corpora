Clauses are labelled either IP or CP with an extended label in every case indicating type. Declarative matrix IPs are labelled IP-MAT, imperatives IP-IMP, and subordinate IPs, that is, those dominated by a CP, IP-SUB. Subordinate clauses with neither a complementizer nor wh- position are labelled IP with an extended label indicating type (e.g. infinitive IP-INF, small clause IP-SMC, etc. All CPs are also labelled for type. The basic types are as follows: 

IP clauses                              CP clauses

IP-MAT          declarative matrix IP   CP-ADV       adverbial clause
IP-SUB          subordinate IP          CP-CMP       comparative
IP-INF          infinitive              CP-DEG       degree complement
IP-INF-PRP      purpose infinitive      CP-FRL       free relative
IP-INF-ADT      adjunct infinitive      CP-QUE       question
IP-INF-DEG      degree infinitive       CP-CAR       clause-adjoined relative
IP-INF-ABS      absolute infinitve      CP-REL       relative clause
IP-ABS          absolute                CP-THT       that complement
IP-PPL          participial adjunct     CP-CLF       it-cleft
IP-SMC          small clause            CP-TMC       tough-movement complement
IP-IMP          imperative              CP-EOP       empty-operator CP

Internal Structure of Matrix Clauses (IP-MAT)

 All clauses except infinitives and imperatives without an overt subject have a subject indicated. See Sections INFINITIVAL CLAUSES and IMPERATIVES. If the subject is not overt, an empty subject is added (see Section EMPTY SUBJECTS). The PPCME2, like the PPCME1, does not generally include a VP level (but see Section VERB PHRASE). This follows from our decision not to make controversial decisions, since in many cases the boundaries of the VP are not clear. Thus, generally, within the clause constituents are phrasal with the exception of all verbal material (auxiliaries, modals, verbs, participles). In addition, particles, sentential conjunctions (including ELSE and ALSO in matrix clauses, single-word interjections within a clause, and floated quantifiers appear without a containing phrasal category.

The specCP position

 The specifier position is not explicitly indicated in our annotation system for any phrasal category; constituents filling this position appear within the phrase in pre-head position (but note that this is not the only use of this position; see below). In adverbial clauses, fronting out of the clause is to the specPP position since the fronted element precedes the preposition (subordinating conjunction) (see Section FRONTING IN SUBORDINATE CLAUSES). Apart from left-dislocated elements, constituents fronted out of the IP are coindexed to a trace in the IP. In subordinate clauses not headed by a preposition, fronted elements appear in specCP before the complementizer position.

Wh-CPs

 Comparative clauses (CP-CMP), relative clauses (CP-REL), free relatives (CP-FRL), clause-adjoined relatives (CP-CAR), questions (CP-QUE), it-clefts (CP-CLF), tough-movement complements (CP-TMC), and a certain type of adverbial (CP-ADV) have both a wh- position and the complementizer position indicated in every clause. This is to allow for the case in which both positions are filled. An empty position is indicated by 0 (ZERO). The wh-operator is coindexed to a trace of the same category. By convention this trace is always the first element in the IP complement, unless it has been extracted from a lower constituent (PP, IP-INF, etc.), in which case it appears within that constituent (see Section POSITION OF TRACES).
